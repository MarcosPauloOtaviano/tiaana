# Salgados da Tia Ana

Site de cardapio e pedidos para salgados, paes caseiros e produtos de padaria. A pagina foi pensada para transformar um catalogo simples em uma experiencia de compra direta: o cliente escolhe os itens, monta a cesta e finaliza pelo WhatsApp.

## O que o site faz

- Mostra os produtos por categoria: salgados e padaria.
- Exibe fotos, precos, opcoes de recheio/preparo e quantidades.
- Calcula o total da cesta automaticamente.
- Aplica condicoes especiais para pedidos maiores.
- Gera QR Code Pix para pagamento antecipado.
- Envia o pedido pronto para o WhatsApp da loja.
- Mantem a cesta salva no navegador enquanto o cliente navega.

## Tecnologias

- HTML
- CSS
- JavaScript
- QRCode.js

## Como abrir

Basta abrir o arquivo `index.html` no navegador. Por ser um site estatico, tambem pode ser publicado facilmente na Vercel, Netlify ou GitHub Pages.

## Objetivo

Esse projeto mostra como um pequeno negocio pode ter uma vitrine bonita, pratica e pronta para receber pedidos sem precisar de um sistema complexo.
